# IM聊天软件开发计划

## 📋 需求文档分析

根据 `需求.text` 文档，系统需要实现以下核心功能模块：

1. **用户管理模块** - 注册、登录、资料管理、资金管理
2. **联系人管理模块** - 查找、添加、分组、状态展示
3. **即时聊天模块** - 会话管理、消息类型、红包转账、辅助功能
4. **群组聊天模块** - 创建、权限管理、特色功能
5. **朋友圈功能** - 信息流、发布、互动、站点列表
6. **后台管理系统** - 权限组、功能配置、资金管控、内容安全

## 📝 开发规范

### 代码规范
1. 遵循现有架构模式：Handler → DAO → Model
2. 所有时间字段使用 `int64` 时间戳
3. 金额字段使用 `int64`（单位：分）
4. 使用事务处理资金操作
5. 统一错误码定义在 `code_msg` 包中

### API设计规范
1. 使用 Protocol Buffers 定义API
2. 统一响应格式（JsonSuccess/JsonErrorFixation）
3. 参数校验使用 proto validate 规则
4. 业务逻辑校验在 Handler 层实现

### 数据库规范
1. 使用 GORM 进行数据库操作
2. 软删除使用 `DeletedAt` 字段
3. 索引合理设计（查询字段、唯一约束）
4. 事务处理关键操作

---

## 🔍 注意事项

1. **资金安全**：所有资金操作必须使用事务，确保数据一致性
2. **通知消息**：全局不可删除、不可静音，确保用户及时查看
3. **多端同步**：关键操作需要实时同步到所有在线设备
4. **性能优化**：大文件上传、消息列表分页、WebSocket连接管理
5. **安全防护**：验证码、登录锁定、权限校验、内容安全
